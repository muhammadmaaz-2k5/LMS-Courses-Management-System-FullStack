# Maaz LMS - Agile Configuration

This directory contains the agile project tracking configuration for the Maaz LMS project.

## Structure

| File | Purpose |
|------|---------|
| `README.md` | This overview file |
| `cycles.json` | Sprint/cycle definitions with goals and deliverables |
| `phases.json` | Development phases mapping to cycles |
| `milestones.json` | Key project milestones and acceptance criteria |
| `config.json` | Project-wide configuration (ports, env, tools) |
| `resources.md` | Tech stack and resource requirements |
| `progress.md` | Current progress tracking and status |

## Usage

- Update `progress.md` at the end of each sprint
- Update `cycles.json` when adding or modifying sprints
- Update `milestones.json` when milestones are completed or added
- Update `config.json` when project configuration changes
